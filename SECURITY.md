# Security Policy

## Supported Versions

Currently, Kimi CLI only provides security support for the latest version.

## Reporting a Vulnerability

Please report a vulnerability via the [l3tchupkt/bugpilot - Security](https://github.com/l3tchupkt/bugpilot/security) page, or open an [issue](https://github.com/l3tchupkt/bugpilot/issues) if it can be published publicly.
